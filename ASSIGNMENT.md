# Тестовое задание: цифровая визитка (backend)

## Цель

Продемонстрировать навык использования технологий стека вакансии. Оценивается качество инженерных решений, а не объём кода. Время на выполнение не ограничено.

## Задача

Создать backend-приложение «цифровая визитка», которое представляет разработчика как специалиста. Данные доступны через GraphQL API и **Apollo Sandbox**.

### Обязательный стек

- Git
- TypeScript
- Node.js
- NestJS
- Prisma
- GraphQL
- Docker

В вакансии также указаны PostgreSQL, S3 storage и Claude Code. PostgreSQL используется как СУБД под Prisma.

## Содержимое backend

1. **Профиль**
   - имя;
   - краткое описание;
   - ссылки на GitHub, LinkedIn или другие профессиональные ресурсы.
2. **Навыки** — список.
3. **Опыт работы**
   - компания;
   - должность;
   - период работы;
   - достижения.
4. **Проекты**
   - название;
   - ссылка на проект или репозиторий.

## Требования

- Приложение предоставляет **Apollo Sandbox**.
- При запуске база данных **автоматически подготавливается** (миграции) и **заполняется** данными автора (seed).
- Приложение корректно работает **после запуска с нуля**.
- API позволяет одним запросом получить профиль и связанные данные:

  ```graphql
  query {
    profile {
      name
      description
      skills {
        name
      }
      experience {
        company
        position
      }
      projects {
        name
      }
    }
  }
  ```

- Структуру GraphQL API, схему БД и архитектуру выбирает исполнитель.
- Бизнес-логика, работа с данными и GraphQL API имеют **разумное разделение ответственности**.

## Критерии оценки

- Структура приложения и разделение ответственности.
- Работа GraphQL с вложенными данными и оптимизация запросов к БД (избежание N+1).
- Взаимодействие с базой данных.
- Инициализация и заполнение базы данных.
- Читаемость и поддерживаемость кода.
- Корректная работа приложения после запуска с нуля.
